# 【清廉医院建设】分级分类警示教育丨中纪委严查讲课费

> 更新时间：2026-09-16 (UTC+8)

// 

**一、“讲课费”“课题费”“咨询费”，中纪委严查变相受礼。**
近日，中纪委在《严肃查处违规受礼行为》一文中明确，据新修订并已于去年1月1日开始施行的《中国共产党纪律处分条例》规定，违规受礼行为主要包括三类：一是收受可能影响公正执行公务的财物；二是收受明显超出正常礼尚往来的财物；三是以讲课费、课题费、咨询费等名义变相受礼。
**二、议题、课时、收费标准，学术会议监管细化。**
2023年医药纠风文件提出“重点关注假借学术活动名义，收受‘红包’、回扣的问题”后，一批医药行业会议延期、取消。之后，有医务人员表示院内对学协会参会的审批变得更加严格，对医药企业会议更是“少参加、不参加”，也有医院开始清退往年讲课费。
 // 

不过，严查并不等同于“一刀切”，尤其在医药行业，新的研究成果、治疗方法和手段不断涌现，学术会议与学术推广是推动新药物、新疗法真正惠及患者的重要手段之一。2023年，针对当时一批行业会议延期、取消等现象，国家卫健委回应“规范开展的学术会议和正常医学活动是要大力支持、积极鼓励的”“需要整治的是那些无中生有、编造虚假学术会议的名头，进行违法违规利益输送，或者违规将学术会议赞助费私分的不法行为”。
  //  

2023年底国家卫健委发布的《关于印发医务人员学术讲课取酬工作提示的通知》国卫办医急函[2023]469号文件中明确了对医务人员学术讲课取酬行为有要求——应该遵守学术讲课取酬“六个应当”和参与学术讲课“六个严禁”。

**医务人员学术讲课取酬行为须符合“六个应当”：**

1.会议举办方和授课邀请方应当为国家机关、事业单位、医疗卫生机构、科研院所、高等院校和社会组织，且合规合法举办学术活动，并能为医务人员学术讲课提供佐证材料。

2.会议举办方应当合理合规合法发放酬劳。

3.医务人员参与学术讲课前，应当履行所在医疗卫生机构的有关审批手续。

4.医务人员参与学术讲课内容应当客观、公正，具有相应科学证据。

5.医务人员参与学术讲课的交通出行及住宿、用餐等接待，应当符合中央八项规定精神及有关差旅、公务接待管理的规定。

6.学术讲课活动应当符合法律法规规定的其他条件。

**医务人员参与学术讲课严禁有以下行为（简称“六个严禁”）：**1.直接接受医药行业相关企业给予的讲课费，以及贵重礼品和各种有价证券、支付凭证等财物。

2.以编造学术讲课虚假理由或取酬明显超过本行业学协会推荐的讲课取酬标准等方式接受利益输送。

3.影响正常业务工作。

4.将学术讲课与引进、使用、推介医药产品挂钩或利用职业身份进行商业广告宣传。

5.学术讲课期间接受可能影响廉洁行医的各类财物或宴请、旅游、健身、娱乐等活动安排。

6.向会议举办方、授课邀请方和医药行业相关企业报销应由个人支付的费用。

 // 

从以往被通报案例来看，违规学术会议主要风险点包括议题空泛、虚增时长、超标准支付等，相应的，企业主办或与第三方合作合规举办学术会议则需要针对高风险因素加强审核、留存证据。

例如，讲课费用标准方面，参考财政部、中央组织部等2016年联合印发《中央和国家机关培训费管理办法》规定，院士、全国知名专家每学时讲课费一般不超过1500元（税后，下同）；正高级技术职称专业人员每学时最高不超过1000元；副高级技术职称专业人员每学时最高不超过500元。讲课费按实际发生的学时计算，每半天最多按4学时计算。

严格监管带来的短期阵痛下，曾经处于灰色地带的会议课程将进一步减少，留下更透明、更“技术驱动”的学术会议，医药行业也将向着良性竞争发展。
