# 高血压风湿免疫科蒙婷：中西医结合治疗 收获患者好评无数

> 更新时间：2026-09-16 (UTC+8)

**“阿姨，您又来住院了，这回是哪儿不舒服？”**3月26日14时20分许，**新疆维吾尔自治区第八人民医院（自治区妇幼保健院）高血压风湿免疫科副主任蒙婷**刚下门诊回到病区，就遇到了相识10多年的“老朋友”——71岁的马老太和她的老伴。

简单寒暄后，蒙婷详细询问了马老太这次住院的原因，便叮嘱他们**“有啥事儿，尽管来找我”**。转身，蒙婷就接到科里一名患者因病情不稳定亟需抢救的消息。顾不上片刻喘息，蒙婷赶紧赶到病房……一个午休，蒙婷就在这样的忙碌中度过了。

自治区第八人民医院高血压风湿免疫科副主任蒙婷为老人查体

忙碌，是蒙婷每天的工作状态。从门诊到病房，从医院的患者到手机微信里的老患者，蒙婷每天都在与病魔“作斗争”，但她也早就摸索出一套自己的模式，那就是**“尽心为患者服务，与病魔抗争不眠不休”**。也正是如此，蒙婷所在的高血压风湿免疫科，即便在医院发展转型阶段，也依然是医院的**“王牌科室”**之一。

**患者都说她像“家人”**

因为医院医生护士的态度好、医院的服务好，马老太和老伴成了自治区第八人民医院的“铁杆粉丝”。

**“10年前，我们就选择到这家医院看病，虽然医院不像其他医院高楼林立，但是医生护士的态度好，服务也很好，我们都习惯来这里。”**也是在10年前，马老太就认识了蒙婷，对她印象深刻，**“她细心、耐心、热心，就跟我们的‘女儿’一样，贴心得很。”**

来自克拉玛依市的周先生住进高血压风湿免疫科后，没几天牙又疼了起来，他**“吃不好，睡不着”**。因行动不便，周先生无法躺到口腔科的治疗椅上，作为周先生的主治医生，蒙婷看在眼里急在心里，主动联系口腔科医生到病区来治疗，还全程陪着林先生接受拔牙治疗，让患者林先生感觉到家人般的温暖。

**蒙婷叮嘱老人用药**

不止他们，病区里的患者对蒙婷都无一例外的好评。**“她特别热心”“中西医治疗都会”“特别认真负责”……**

蒙婷确实将患者的一件件小事当成重要的事，尽心尽力为患者解决。**从医近20年，**蒙婷也得到了众多患者及家属的认可，她感到非常欣慰，觉得自己没白付出。

自2006年中西医结合专业本科毕业后，蒙婷就来到自治区第八人民医院，被分到了高血压风湿免疫科。**蒙婷记得，**当时高血压风湿免疫科是全院病人最少的科室，“就四五个病人，其他科室的病房都住满了，而且口碑也特别好，楼上楼下鲜明的对比，我当时并不想留下。”

但科室主任包永江的一言一行改变了蒙婷。“包主任带着我们干，周六周日都来查房，节假日他也带着我们坚守在工作岗位上，并要求我们每个人都要热情、耐心、专业地为患者服务，慢慢地，情况有了些许变化。”**蒙婷说，**曾经常去其他科室的有些患者突然发现，自己的病友住进了一楼病区。

在包永江的带领下，蒙婷和同事们十几年如一日的坚守，终让高血压风湿免疫科成为患者心目中的**“口碑科室”**，病区43张床，几乎满员。2024年，科室收治病人量全院第一。

**推广中西医结合治疗模式**

科室不断成长，勤学好钻研的蒙婷也没有停下学习的脚步，2011年攻读研究生，2018年攻读博士。由于长期坚守临床一线，蒙婷打下了扎实的临床诊疗基础，为中西医结合诊疗在科室的后期推广奠定了基础，也让她很快从科室一众医生中脱颖而出。

在她看来，科室收治的患者中老年人居多，大部分都是高血压、冠心病、慢阻肺、2型糖尿病等，不少患者存在两种以上的基础疾病，尤其是老年人多病共存，中西医结合的综合诊治就更具有优势。

“西医在急危重症患者的抢救上确实很有优势，但在治疗慢性疾病尤其是多种基础疾病共存的患者时，中西医结合效果更好。”**蒙婷说，**心肺就像孪生兄弟，“比如有些患者因为咳嗽、气短，误认为是呼吸道的疾病，实际上可能是心脏出现了问题。但也有患者因为胸闷气憋，检查心脏发现没有问题，实际上是患有哮喘，采用西医手段迅速评估病情鉴别诊断，联合中医体质辨证康复调理，实现了心肺同治。”

她也确实充分发挥中西医结合治疗优势。有些患者初诊高血压，往往不愿也不接受长期口服药物。特别是高血压Ⅰ级的患者，服药依从性很差，“让他吃一辈子降压药，他肯定不想，但是通过早期的中医干预，就能得到很好的控制。”在蒙婷的印象中，一位老太太因为心衰，整天乏力气短，来院就诊时双腿浮肿，吃了西药不管用，就慕名找到了蒙婷。蒙婷结合老太太的症状开具了中药给予调理，半年之后老太太的腿不肿了，全身也有力气了，她的老伴说“她走路都带风”。

一位老年男性患者因呼吸道急性传染病而导致咳嗽不止，吃了很多西药都不见效果，找到蒙婷希望能再开点儿有用的西药。得知这位患者的情况后，蒙婷为他开了5付中药。“一开始他还有点将信将疑，但是5付药过后患者的咳嗽病好了。”**蒙婷说，**这位患者从此成了蒙婷的忠实粉丝，一家人生病都找她看。

粉丝越来越多，蒙婷也越来越有信心，在中西医结合治疗道路上也迎来了事业发展的转折点——在**导师李风森教授**的启发下，2019年蒙婷在科室内逐渐推广中西医结合治疗这一模式，为科室发展开启了一扇新的大门。她也获得了到北京知名医院进修学习的机会，到中国中医科学院西苑医院学习心血管疾病的中医治疗，到北京朝阳医院加深了对呼吸疾病的西医诊疗，从此她便充分发挥中西医结合治疗优势，用自己的专业技能“牢牢”粘住患者。

在中西医结合治疗的道路上，蒙婷越走越远。她获得了自治区青年岐黄学者人才培养项目，在科研上也有了成果。凭借自己的真本事，2023年蒙婷成为高血压风湿免疫科副主任，她把科室发展的重任扛在肩上，努力打造特色科室。

如今，在蒙婷的努力下，高血压风湿免疫科在中成药、中草药治疗上效果显著，成为科室的一大特色。

**“我们还计划为患者开四季养生膏方，为病区患者免费提供降压茶、养心茶、安神茶，后期，我们也会重点培养中西医结合人才，为我们这个科室的发展贡献年轻力量。”**蒙婷对科室未来的发展做了初步的规划。
